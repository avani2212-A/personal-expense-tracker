# Personal Expense Tracker

A simple Python-based desktop application for recording, managing, and visualizing personal expenses.

## Features

- Add new expenses with date, amount, category, and description
- View recorded expenses in a table
- Delete selected expense entries
- Store expense data in a CSV file
- Visualize category-wise expenses using a pie chart

## Technologies Used

- Python
- Tkinter
- CSV
- Matplotlib

# Project Structure

## How It Works

The application provides a graphical interface where users can enter expense details such as amount, category, date, 
and description. The data is stored in a CSV file and can be viewed or deleted through the application.
The project also includes a category-wise expense visualization using a pie chart.
